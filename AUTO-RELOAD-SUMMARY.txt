   • Color-coded console output with timestamps
   • Lightweight and fast
   • Best for: Static file serving with monitoring

   • Automatic API documentation at /docs
   • Modern async support
   • Health check and file listing endpoints
   • Best for: API development, async applications

   • Perfect for developing the snake game
   • Best for: Terminal game development

================================================================================
ADVANCED TIPS
================================================================================

💡 Change Port
─────────────
Edit the server file and change:
  app.run(host='0.0.0.0', port=8080, debug=True)

💡 Watch Additional File Types
──────────────────────────────
Add to dev-server-livereload.py:
  server.watch(os.path.join(BASE_DIR, '*.json'))
  server.watch(os.path.join(BASE_DIR, '*.md'))

💡 Run Multiple Servers
───────────────────────
Terminal 1: python3 dev-server-livereload.py  # Port 8000
Terminal 2: python3 dev-fastapi.py            # Port 8001 (edit file)

💡 Custom Watch Patterns
───────────────────────
Modify watchdog patterns in dev-watch.py to match specific needs

================================================================================
TROUBLESHOOTING
================================================================================

❌ Port already in use
─────────────────────
  lsof -i :8000
  kill -9 <PID>

❌ Dependencies not found
─────────────────────────
  pip3 install -r requirements-dev.txt

❌ LiveReload not refreshing
────────────────────────────
  1. Check browser console
  2. Hard refresh (Ctrl+Shift+R)
  3. Ensure file is in watched directory

❌ Permission denied
───────────────────
  chmod +x start-dev.sh *.py
